# Minecraft main-menu video

The in-game menu uses `bg_5rain.mp4`, one of the 1920×1080 Minecraft
recordings supplied for Fathom. The source recording stays outside the
repository. Minecraft 1.8.9 has no built-in video decoder, so the checked-in
runtime asset is a prepared 30 fps texture sequence:

`minecraft/fathom-optimizations/src/main/resources/assets/fathom-optimizations/textures/menu/bg_5rain/frame_000.jpg`

through `frame_299.jpg`.

Regenerate it with:

```powershell
pwsh tools/prepare-main-menu-video.ps1
```

The script selects ten seconds of the supplied recording and performs a 24-frame
end-to-start dissolve so the 300-frame loop closes without a jump. Lanczos
scaling, Gaussian defocus, restrained grading, and a vignette are baked once by
FFmpeg. At runtime a daemon thread decodes one frame ahead into two reusable
direct buffers; the render thread updates one texture at 30 Hz. The Fathom UI is
drawn afterward at framebuffer resolution and is never baked into or softened
with the background.

`main-menu-bg.png`, generated by `tools/prepare-main-menu-poster.ps1`, remains
only as the first-frame and decode-failure fallback.

`bg_5rain` was recorded in a community-made world. Both assets above derive from
it, so both carry its creator credit; see [`ATTRIBUTION.md`](../../ATTRIBUTION.md).

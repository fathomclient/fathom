Design study — not production artwork

Fathom symbol concepts

Six vector marks built from flat geometry on a 64×64 grid. No gradients, no strokes, no type inside the mark. Each is a base form in currentColor plus one accent element, so flattening to a single colour leaves a mark that still reads.

Minimum bar weight is 10 grid units — 2.5 px at 16×16 — and the smallest negative gap is 5 units. Every concept is shown two-tone, single-colour, on application tiles, and in situ.

06 was chosen. It is built out in assets/brand/ and shipped as the application icon; this sheet stays as the record of the decision. The other five are studies and are not artwork.

Wordmark

Set in Geist, the face the launcher already ships (desktop/src/lib/fonts/Geist-Variable.woff2, weights 100–900). Nothing is redrawn and nothing is scaled horizontally — the only variables are weight, case and tracking. The symbol is designed to stand alone; the wordmark is a lockup, not the logo.

A — uppercase, 600, +0.30em tracking (recommended)
FATHOM
Wide tracking reads as an instrument label rather than a logotype, which is the register the rest of the product is in. Holds at small sizes and survives next to a dense symbol.

Grid 64×64, safe area 8 units. Accent #c4303c (--accent), light text #f4f6f9. The accent is exposed to CSS as --fathom-accent; set it to currentColor for single-colour output, or to #fff for a knockout on an accent tile.

The 16 px column here is the 64-unit drawing scaled down, which is the honest worst case. Whichever concept is chosen gets a hand-tuned 16 px and 20 px variant snapped to whole pixels before it ships, the way icon sets are normally built — so the small sizes below are a floor, not the finished result.

If the wordmark renders in a system face rather than Geist, this page was opened straight from disk and the browser refused the local font file. Serve the repo over HTTP to see it correctly.

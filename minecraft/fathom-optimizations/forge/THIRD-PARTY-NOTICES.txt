Fathom for Forge -- third-party software in this jar
=====================================================

This jar is Fathom's client (Apache-2.0, LICENSE_fathom-optimizations) with
three libraries bundled, because Forge 1.8.9 provides neither Mixin nor an ASM
new enough for it. The Fabric build carries none of them: Fabric's loader
supplies its own.

  Copyright (c) 2000-2011 INRIA, France Telecom. All rights reserved.
  BSD-3-Clause License, below. https://asm.ow2.io

  MODIFIED: org/objectweb/asm/Type.class. Type.getTypeInternal returns an
  internal-name type for a string that is not a descriptor, where ASM 9.6
  throws. Forge 1.8.9 relies on ASM 5's behaviour there. Nothing else in ASM is
  changed. The five classes org/objectweb/asm/commons/Remapping*Adapter.class
  are ASM 6.2.1's, unmodified; ASM 9 no longer has them and Forge uses them.

Not in this jar: Forge, Minecraft, or the mapping tables used to build it.
The build reads Forge's deobfuscation table to rename Fathom's references; the
table itself is not copied into the output.
